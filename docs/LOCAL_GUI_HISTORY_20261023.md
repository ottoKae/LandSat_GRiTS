**整格网日合成**：在本仓库目录执行以下命令，打开 **http://127.0.0.1:8766**：

```powershell
.venv\Scripts\python.exe -m grits_resolver.daily_viewer `
  --tile-config ..\GRiTS-Resolver\examples\shenzhen_landsat_daily.json `
  --port 8766
```

该入口只加载 Landsat，默认查看 49QHE 同一 UTC 日内的多景镶嵌。Path 表示轨道路径，Row 表示沿轨景行：
同 Path 不同 Row 分别保留，同日不同 Path 也可参与。QA 筛选后逐像元选择；同分按实际时间、场景 ID 排序。
全部请求波段和 QA 来自同一景，缺测不从其他日期填补。切到“像元来源”可检查各景贡献；点击查看 Path、Row、精确时间和物理量。

日合成所需清单应完整检索与瓦片相交的当天场景，不能只选一景或使用 `--limit-per-search 1`。
本次补景不按整景云量排除，读取时再按像元 QA 选择；整景多云不代表目标格网没有可用像元。

真彩色和假彩色默认采用 **反射率 0–0.30、线性 γ=1**，避免按暗海面分布过度提亮。
也可切换 P2–P99 自适应拉伸查看细节。仅 PNG 颜色改变，源 Zarr 和查询值不变。
月度镶嵌作为辅助显示保留，不改变逐景归档格式。当前两天分别为 2025-12-08 的 P122/R044+R045、
2025-12-17 的 P121/R044+R045；属于同轨相邻景的真实测试，不是同日跨 Path 实测。
日合成页面展示红、绿、蓝、近红外，完整产品变量在下方单景浏览器中查看。
详见 [Resolver 格网 GUI](../../GRiTS-Resolver/README.md#landsat-整格网日合成-gui)。
完整目录查询、补景清单和逐像元核对见 [同日多景测试记录](evidence/landsat-daily-20261021/README.md)。
页面已通过 [桌面／手机浏览器验收](../../GRiTS-Resolver/docs/evidence/20261021-landsat-gui/browser-acceptance.json)，包含两天的全部显示模式、来源追溯、拉伸切换与 PNG 导出。

**单景与全部变量**：

在仓库目录运行，随后用浏览器打开 **http://127.0.0.1:8765**：

```powershell
.venv\Scripts\landsat-grits.exe gui outputs\pilots\shenzhen-20261021
```

查看新增两景的完整变量时，将上述目录换为 `outputs\pilots\shenzhen-daily-20261021`。

GUI 自动扫描指定目录中的已提交 Zarr，提供格网地图、传感器对照和全部变量图集；可切换格网、产品、轨道、场景、变量组和波段，查看合成影像、单波段与有效性掩膜，并导出当前预览 PNG。页面与影像均由本机提供，无需在线底图或额外前端安装。关闭启动终端或按 `Ctrl+C` 停止服务。

首批测试区域为深圳大学粤海校区所在的 **49QHE**。四类产品分别归档，首批 OLI 的两条 WRS 轨道在不同日期各保留一景；对照和图集按“产品库 × 轨道”展示。校园按钮定位到标注来源的校园代表点。早期 `17MPU` 完整瓦片及 `50RKV` 小窗口测试仍保留，启动时可改为对应批次目录。不要将保存问题证据的 `*-initial-warp` 批次作为正式数据。

地图由各变量组的实际 UTM 格网重投影到 Web Mercator。L2 按逐景 `scale/offset` 显示物理量；L1 保留 DN；QA 显示原始位编码值。MSS 没有蓝光波段，使用近红外／红光／绿光假彩色。预览采用降采样和各图自身的百分位拉伸，适合查看空间分布，不能直接用颜色比较跨日期、跨传感器的数值变化。掩膜表示有效像元，**不表示无云**。

启动方式、图例解释和边界见 [GUI 使用说明](GUI.md)。
