# 本地格网浏览器

GUI 读取本地已归档的 Zarr，展示已有数据，不执行检索、下载或修改归档。它沿用原有的传感器族、产品级别、变量组和时间轴，目录根据实际元数据生成。

轨道菜单将同一产品库中的 WRS 路径分别列出，场景菜单只包含所选轨道。对照与图集按“归档 × 轨道”展示，并标明各景的 UTC、Path、Row 和产品身份。未知轨道逐景列出，不当作一条共同轨道。详见 [光学轨道读取](OPTICAL_TRACKS.md)。

## 启动

在仓库目录执行：

```sh
landsat-grits gui outputs/shenzhen-l2
```

打开 http://127.0.0.1:8765 。若端口已被占用，可指定 `--port 8766`。服务仅监听本机 `127.0.0.1`，按 `Ctrl+C` 停止。无需 npm、在线底图或额外 Python 依赖。

将路径替换为自己的归档目录；没有影像时可先运行 [离线示例](QUICKSTART.md#先运行离线示例)。

指定目录需要同时保留 `.zarr` 与相邻的 `.zarr.commits.json`。目录异常或存在未提交数据时会显示错误，不会尝试修复。下载完成后重新加载页面可更新目录；读取时使用原有文件锁，同一个库不应同时进行写入。

## 页面内容

| 视图 | 用途 |
|---|---|
| 格网地图 | 选择格网、产品、场景、变量组与波段；查看空间分布、经纬网、格网边界、比例尺和图例 |
| 传感器对照 | 并列查看不同产品的单景 RGB；MSS 显式使用假彩色，现代光学产品可使用自然色 |
| 全部变量 | 按归档和变量组列出所有波段，包含光学、热红外、连续辅助变量和 QA；点击进入地图 |

地图支持缩放和平移。49QHE 提供校园定位按钮，标记深圳大学粤海校区的“校园代表点（OSM）”；放大预览不会提高影像分辨率。导出的 PNG 是当前影像预览，不是原始分辨率 GeoTIFF，也不携带 Zarr 的完整元数据。

## 数值与颜色

- **L1**：显示原始 DN，不将恒等 `scale/offset` 当作反射率或温度标定。
- **L2**：先应用 `valid`，再按当前时间、波段的 `scale/offset` 转换。反射率无量纲，地表温度单位为 K，其他变量使用自身单位。
- **单波段与 RGB**：对当前降采样预览的有效值做百分位拉伸。每幅图独立拉伸，颜色不提供跨传感器、跨时间的统一定量尺度。
- **QA**：显示原始整数编码类别；颜色区分编码值，不表示质量从低到高。QA 值的位定义随产品而异，页面不自动去云。
- **有效性掩膜**：由 `valid` 与 `present` 判断；QA_RADSAT 的有效 0 不等于相应位置存在光谱观测。`ST_QA` 是连续温度不确定度，归在辅助变量中。

数值范围和有效比例来自当前预览采样，不替代全分辨率统计。原始像元、比例系数和来源仍保存在 Zarr 中；需要分析时使用 [Python 读取接口](../README.md#python-读取)。

## 空间与覆盖

影像按每个变量组自身的 CRS、变换和尺寸转置并重投影到 EPSG:3857。全色组如存在，使用其独立的 15 m 格网。格网线来自归档保存的 MGRS 多边形；栅格范围来自实际数组，二者不必完全重合。地图不把 UTM 数组直接当作经纬度图片铺放。

对照和图集在每个“归档 × 轨道”中选取最接近当前观测日期的一景，并标明完整 UTC
和场景身份；当前轨道保留手动选择的场景。各卡片可能来自不同日期，未进行光谱响应校正。
缺测区保持透明，不从另一轨道或日期补齐。日／月／年合成显示由 [Resolver](RESOLVER.md) 提供。

## 实现

入口为 `landsat-grits gui`；后端位于 `src/landsat_grits/viewer.py`，静态页面位于 `src/landsat_grits/web/`。后端只向页面提供目录与有界预览，使用现有 NumPy、Zarr、Rasterio 和 Python 标准库。原始下载数据无需复制或转换成新的 TIFF。

重投影使用 Rasterio 的数组重投影接口，掩膜通过透明通道表达，详见 [Rasterio 重投影接口](https://rasterio.readthedocs.io/en/stable/api/rasterio.warp.html)及[有效性掩膜说明](https://rasterio.readthedocs.io/en/stable/topics/masks.html)。
